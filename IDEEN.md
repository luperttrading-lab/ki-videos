## Claude Code auf dem Handy oder am Computer: was geht wo?

Angestoßen von: OpenCode Browse (Frage des Nutzers, 09.11.2026)

- Cloud-Sitzung (claude.ai/code, Claude-App): läuft in einem Container bei Anthropic, leerer Browser ohne deine Logins
- Claude Code am Computer (Terminal oder Desktop-App): deine Dateien, dein Browser (Claude in Chrome, OpenCode Browse)
- Brücke: Remote Control (`claude remote-control` bzw. Desktop-App), damit steuerst du die Sitzung am Rechner vom Handy aus
- Konnektoren (Gmail, Kalender, Drive, GitHub): gehen auch vom Handy, ganz ohne Browser
- Faustregel: Konnektor, wenn es einen gibt; Browser-Brücke nur für Seiten ohne Konnektor oder Programmierschnittstelle
