OpenCode Browse: KI-Agenten im echten Browser

Erklärvideo · 7:52 min · Stand 8. November 2026

Begriff
Erklärungen erscheinen hier, sobald im Video ein Fachbegriff fällt.

Mit OpenCode Browse benutzen KI-Agenten deinen echten, eingeloggten Browser: deine Tabs, deine Logins. Das Video erklärt, wie das technisch funktioniert, wie es sich von Claude in Chrome unterscheidet, was es wirklich kostet und warum Prompt Injection das größte Risiko ist.

Begriffe im Video

Cookies
Mini-Dateien, mit denen Webseiten dich wiedererkennen und eingeloggt halten
Coding-Agent
KI, die selbstständig programmiert, z. B. OpenCode, Claude Code, Codex
Open Source
Software mit öffentlichem Quellcode: jeder kann sie prüfen und nutzen
Claude Code
Anthropics Coding-Agent für die Kommandozeile (Terminal)
MCP
Model Context Protocol: offener Standard, über den KI-Agenten Werkzeuge anschließen
Relay
Vermittlungsstelle auf deinem Rechner, die Befehle an den Browser weiterreicht
Captcha
Test, ob ein Mensch vor dem Bildschirm sitzt, z. B. Bilder anklicken
Zwei-Faktor-Anmeldung
Login mit Passwort plus Einmalcode, z. B. aus einer Authenticator-App
Ollama
kostenloses Programm, das KI-Modelle auf dem eigenen Rechner ausführt
Token
Wortstück: KI-Modelle zählen Text und Kosten in Tokens
Tool-Aufruf
Befehl des Modells an ein Werkzeug, z. B. „klicke hier“ oder „lies die Seite“
API-Schlüssel
Zugang zu einem KI-Modell per Programm: bezahlt wird nach Verbrauch statt per Abo
Playwright MCP, Chrome DevTools MCP
kostenlose Werkzeuge von Microsoft und Google, mit denen KI-Agenten Browser steuern
Prompt Injection
versteckte Anweisungen in Texten oder Webseiten, die eine KI befolgt, obwohl du sie nicht gegeben hast
Browserprofil
getrennter Bereich im Browser mit eigenen Logins, Cookies und Lesezeichen
